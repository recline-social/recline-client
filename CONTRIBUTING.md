# Contributing

Thanks for your interest in Recline. This repo is published for **transparency and security auditing** — the primary contribution we welcome is security research.

## Security issues

Please do **not** open a public issue for security vulnerabilities. See [SECURITY.md](SECURITY.md) for responsible disclosure.

## Bug reports

Open an issue with:
- What you expected to happen
- What actually happened
- Steps to reproduce
- Browser and OS

## Pull requests

We review pull requests on a case-by-case basis. For significant changes, open an issue first to discuss.
