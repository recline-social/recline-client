# Code of Conduct

## Our Standards

- Be respectful and constructive in all interactions
- Focus on the code and the ideas, not the person
- Security research is welcomed — see [SECURITY.md](SECURITY.md) for responsible disclosure

## Scope

This applies to all interactions on this repository — issues, pull requests, and discussions.

## Enforcement

Violations can be reported to contact@recline.social. We reserve the right to remove comments or ban contributors who act in bad faith.
